# E5 — Risk-Adaptive Viewpoint Planning and Evidence-Quality Improvement

E1–E4 retain their identifiers and original results. E5-A tests accepted-map geometry, first-hit occlusion, static feasibility, budgets, coverage union, reproducibility and a bounded exhaustive coverage reference. These software tests establish no fault-detection benefit.

E5-B executes original imperfect sensing, B3.1/thermal and F1. Configuration is experiments/E5.yaml → configs/experiments/E5.yaml. Development seeds 9100–9102 and diagnostic 10100 are disjoint from held-out 11100–11129. Weights and sensing models were frozen before held-out execution. All four methods share each trial's initial snapshot, complete candidate pool, seed, noise distribution and budget. Four bounded CPU processes distribute independent scenario classes; viewpoints within a seed are correlated and are not independent replicates.

The 18 declared classes cover healthy recent/stale, localized warning, partial initial view, L2, self-occlusion/partial view, competing asset needs, image-only thermal, process warning/critical access, repeated overlap, no feasible geometry, insufficient registration proxy, out-of-calibration range, inconclusive reinspection, missing metadata, tight budgets and no-go routes. Report achieved conditions: a nominal "healthy recent" scan may still have insufficient full-surface coverage, and a shared calibrated asset set limits multi-asset measurement comparisons. Do not claim complete recent coverage where the public scan did not establish it.

Run: `.venv/bin/twinguard experiment run E5 --config experiments/E5.yaml --output-dir <new-directory>`. Report: `.venv/bin/twinguard experiment report --run-dir <directory>`. The bounded parallel execution helper accepts `python scripts/run_e5_shards.py --output <new-directory> --workers 4`. All output directories must be new; raw prior runs are preserved.

Metrics separately report nominal predicted area, actual associated area, qualified analytic area, patch count, registration outcome, inconclusive scans, localized overlap recall by 10/20/30/50 mm, view/time/travel/data costs and planning/processing times. Unknowns and no-plan outcomes remain in denominators. H1–H6 are hypotheses: a view-selection proxy can underperform the fixed schedule. No held-out tuning or underlying detector improvement is claimed. Full numerical results and acceptance statuses are in PHASE6_VALIDATION.md.
