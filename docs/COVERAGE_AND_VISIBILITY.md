# Coverage and visibility

Reference cells group accepted triangle-centroid area quadrature samples by asset and 80 mm world voxel. Cell area is the sum of actual accepted triangle areas, and center is their area-weighted centroid. IDs are sorted (asset, voxel coordinates), stable for the pinned reference/configuration. Total area is preserved. This is a discrete nominal-surface approximation: one associated point does not certify every continuous square millimeter of a cell.

Open3D CPU first-hit raycasting uses only that accepted mesh. Actual configured nominal rays determine in-range visible cells; incidence is |normal·ray|. Predicted suitability additionally gates incidence ≥0.3, calibration range, fidelity, patch sampling and registration support. Range/noise dropout and current obstructions can make real acquisitions differ. The planner never imports the physical scene reader or simulator triangle/fault labels.

Actual observed cells are estimated by nearest public registered measured point to a cell centroid within 60 mm. Duplicates count once. Registration uncertainty is retained. Qualified cells require actual observed support, valid registration, existing calibrated localized_relative analytics and valid B3.1 patch support ≥10; the conservative patch box half-width is patch scale/√3. Invalid registration or missing calibration leaves observed/weak support, not qualified evidence. Current coverage is unioned only within the declared 3,600-second horizon. Actual, weak, qualified and finding fields remain separate.

Predicted visible area, predicted usable area, actual associated area and qualified analytic area have different meanings. They must not be substituted for one another. The point-density proxy is based on angular sampling and range/incidence, not a fixed return density. Expected new coverage subtracts the current qualified-cell union; repeated cells never add utility twice. Report prediction errors only with matched area/support definitions.
