# Operating and thermal residual analytics

Calibration is explicit and offline, using only declared healthy datasets. The benchmark uses seeds 60–62 and separate steady, increasing and decreasing measured-load sequences. Evaluation seeds 300–304 are disjoint. Static references use steady samples near load 0.5 from the same healthy collection. Conditioned references robustly fit intercept and a causally filtered measured-load feature for each measured channel. A fixed time-constant grid is selected with held-out healthy dataset groups, then refitted on the healthy calibration set. No generator expected-value functions or evaluation faults enter these models.

Inference does not refit. A contextual load sample is eligible only when both its acquisition time and receipt time precede the target observation's corresponding times. This prevents future leakage in offline replay. Dynamic load filtering represents lag rather than subtracting an instantaneous load curve. Missing/stale context and load outside the healthy calibrated range produce explicit qualification. `conditioned_quality` additionally excludes invalid, excessively delayed or corrupted-quality observations; data quality cannot identify every unmarked bias.

OperatingPrediction records measured/predicted value, residual, unit, scale, engineering significance, context sample IDs, times, model and status. Per-channel residual scales have lower bounds (0.4 C and 500 Pa); default operating screen is five scales. These are assumed synthetic engineering thresholds, not equipment safe limits or calibrated probabilities. Sensor faults can legitimately generate residuals; Phase 3 does not decide whether residuals imply an equipment hazard.

Thermal processing reads numeric apparent-temperature arrays, camera metadata and masks. valid_mask means an available measured pixel, not quantitative validity. New saturation_mask marks clipping; pixel_status values are 0 unavailable, 1 quantitative, 2 invalid/dropout and 3 saturated. Saturated and invalid pixels are excluded. Legacy two-array captures without an explicit saturation mask remain loadable but are conservatively inconclusive for residual quantification.

Healthy same-view frames fit per-pixel apparent temperature against the measured causal load feature, with robust scale/support maps. Different image shapes, excessive camera pose changes, missing calibration support, low quantitative coverage or out-of-reference load cause qualification. This is same-view radiometric comparison, not arbitrary-view thermal registration. Median-filtered residual candidates exceed 4 C plus twice the uncertainty score, with four-pixel minimum connected components. Output includes residual, candidate, quantitative and saturation arrays plus bounded image regions; association is explicitly ambiguous without an independent projection model.

The operating EvidenceRecord adapter preserves timestamps, source/model references and quality without fusing modalities. No final severity, hazard policy, green/amber/red assessment or Phase 4 engine is implemented.
