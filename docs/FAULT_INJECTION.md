# Fault injection and ground truth

FaultInjection remains the restricted Phase 0 contract, extended with local centre, positive spatial radii, direction, optional world displacement vector, step/linear evolution, growth duration, persistence, recovery duration, repair time and process variable/target. Old records remain readable. Structural faults default to persistent; thermal/process faults default to recovery at end_at. S2 explicitly grows from 30 to 60 s, stays present beyond its injection end at 90 s, and has no repair event.

Time semantics: start_at initiates the fault; a linear growth interval reaches full amplitude after growth_duration_s; end_at ends injection/active forcing. Persistent faults hold their grown state afterward. Recovering faults decay linearly over recovery_duration_s, or stop at end_at when that duration is zero. An explicit repair_at overrides all subsequent state to the accepted baseline plus any normal expansion. Invalid intervals/directions/extents, missing magnitudes and conflicting duplicate magnitude declarations are rejected. A repair restoration is an explicit modeled event, not an unmodeled physical recovery.

F1 water-wall deformation uses a compact smooth local X/Z ellipse. Define r²=((x-x0)/rx)²+((z-z0)/rz)² and w=max(0,1-r²)³. The displacement is A×w×time_factor along the normalized configured local direction (default +Y). This C2 field is exactly zero outside the ellipse. Both panel/tube surfaces share the same through-thickness displacement; it is not a shell stress solution. Default local centre is (0,0,1.2) m and X/Z radii 0.4/0.5 m. Mesh vertices actually move. Alternative centres/resolutions may undersample a peak; the sampled true maximum is reported separately from the continuous configured amplitude.

F2 translates SUP-01's world pose and vertices by the configured vector. Multiple translations add. Attached equipment receives no unsupported mechanical stress/coupling response; the reference frame stays fixed. F3 adds a compact spatial residual to the actual vertex temperature field. A 12 degC example is supplied; no thermal-camera image is synthesized. F4 adds a pressure/temperature deviation or moves the chosen variable toward an absolute target according to the time factor. The legacy category name abnormal_process_measurement denotes a genuine process-state disturbance here, not sensor corruption. Its units must match the selected variable.

Faults compose additively from the immutable baseline, sorted by stable fault ID. Geometry and thermal effects do not overwrite each other. Absolute process targets combined with another disturbance on that variable are conservatively rejected, even if schedules do not overlap. Other additive effects may be physically implausible; this is not a mechanics validation. Missing scenario assets, inappropriate support/wall attachments, nonintersecting sampled spatial regions and duplicated fault IDs are rejected.

GroundTruthSnapshot and nested FaultState store run/scenario IDs, timestamp, exact typed injection configuration, resolved asset ID, time factor, presence and applied physical quantities. They derive from the injected transformation/field, independently of any detector. Restricted files live in run/restricted with directory mode 0700 and file mode 0600. Public sensor/inspection serialization remains an exact-type allowlist and rejects full snapshots, physical read views, faults and truth records. All run geometry/state files are simulator artifacts, not future analytics observations.

The recursive import auditor checks analytics/fusion/inspection/API packages, including nested modules, relative imports and imports through parent packages. It forbids plant/evaluation/configuration/registry and privileged sensing-read dependencies. This complements typed boundaries; it is not a Python sandbox against deliberate reflection or arbitrary dynamic code. Same-user filesystem access is not a security boundary. Phase 2 gets a deliberately privileged `PhysicalStateReader`, which exposes only timestamped world surfaces, vertex temperatures and process variables; it must turn these into separate SensorObservation/InspectionCapture records before analytics sees them. Evaluation accesses the restricted truth path independently.
