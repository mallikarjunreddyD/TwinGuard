# Virtual LiDAR model

The default headless instrument emits 16 vertical channels × 720 horizontal samples (11,520 rays). Vertical angles span -0.4 to +0.4 rad; horizontal FoV defaults to 1.4 rad about sweep_center_rad. A full 2π sweep excludes the duplicate end angle. One-channel/one-sample cases use their centre angles. Horizontal resolution derives from FoV/sample count. Ranges default to 0.1–20 m. These are scaled-plant simulation parameters, not commercial specifications.

Local +X points forward, +Y left, +Z up. Direction d=(cos(e)cos(a), cos(e)sin(a), sin(e)). Directions are normalized and transformed into world with the true acquisition rotation; origins use the true translation. The current physical scene is independently rebuilt at every event. Open3D CPU RaycastingScene returns the nearest intersection, geometry/triangle IDs and barycentric coordinates. Internal mappings preserve vertex/temperature order for verification, and are never exported as measured semantics. Overlapping primitives are handled by the first visible intersection; the instrument cannot see through an opaque component. A hit before min range still occludes any surface behind it. Missing intersections and rejected returns produce no point, not a zero-range point.

Open3D performs intersections in float32. Known-plane, transformed-coordinate, miss, occlusion and cross-backend tests use 2e-5 m absolute tolerance at mock-up scale. This is a numerical verification tolerance, not hardware accuracy. The explicit numpy_bvh backend builds an AABB hierarchy and performs double-sided Moller–Trumbore intersection in float64; its primitive bookkeeping is private. Both backends implement actual first-hit visibility. Open3D 0.19.0 installed and ran on CPU in this environment; no installation failure is claimed.

Angular sigma (rad) perturbs emitted azimuth/elevation before physical intersections. The instrument reconstructs coordinates from the nominal beam directions, representing unobserved angular error. Range sigma is sigma + range_slope×range (metres); range bias adds a systematic offset. Optional quantization rounds to configured metre increments. Random dropout is augmented by incidence_dropout×(1-|n·d|), clipped to [0,1]. Optional outliers add a uniform bounded range offset. Range bounds apply to both true eligibility and measured return. A valid-return mask reflects the instrument's no-return pattern; it is not a correspondence or ground-truth segmentation map.

True acquisition pose comes from the controller/event override. Reported pose is translated in world by Gaussian error plus a configurable systematic bias and rotated by an XYZ error (Rz Ry Rx) left-composed in world. Public capture metadata contains reported pose and configured per-axis estimated standard deviations only; actual errors and true poses remain private. Public world plots transform measured local points with the reported pose. The default S2 t=60 event moves to X=0.15 m, Y=3.55 m rather than the t=0 X=0, Y=3.4 m view, and uses an independent random stream. No baseline cloud is copied, displaced or assigned perfect point correspondences.

L0 suppresses stochastic noise/pose error for verification; L1 is small-noise incomplete sensing; moderate increases noise/outliers; L2 increases noise, pose errors/dropout and narrows FoV. Narrowing FoV concentrates more rays on the plant, so a degraded scan can have more valid returns while covering fewer angles. Return fraction is not surface-area coverage. Model settings and measured outcomes are both reported, never substituted for each other.

NPZ exports only points_m and valid_returns; PLY contains measured XYZ. Known asset_ids in the capture are the configured target association, not a claim that every point belongs to that asset. Ideal range-error zero is the difference from the backend's own noiseless intersection reference; geometric numerical correctness is checked separately against known geometry. Runtime has no motion distortion, rolling sweep timestamps, reflectance/intensity calibration, multipath, multiple returns, atmospheric scattering or UAV flight dynamics. No registration or deformation detection is performed.
